## How this repo is organized

Each topic folder contains **Pattern-X-Name** subfolders. Each pattern subfolder has:
- A `README.md` with the trigger sentence (how to recognize the pattern) and the code template
- One file per problem solved (e.g. `LC567_PermutationInString.java`)

## Workflow used for every problem

1. Pattern recognition (no hints given) → state trigger reasoning
2. Pseudocode
3. Java (or C++) implementation
4. Review: correctness, edge cases, complexity
